# v0.3.3 — Vail ReRBN and panel refinements

RBN · My signal now receives CW, RTTY, FT8, and FT4 reports through
[Vail ReRBN](https://vailrerbn.com/docs/endpoints), with a larger map,
persistent display settings, and manual refresh.

- Use **View** and **Band** in panel settings (the tune icon). These choices
  are saved per placement, and saving unrelated settings preserves the current
  sort order.
- The compact status row and footer leave more room for the map and receiver
  list. Updated native macOS screenshots show the layout and settings.
- Use **↻** beside Details to refresh reports. Automatic checks run at most
  once a minute per query; manual refresh waits at least 30 seconds between
  requests. Placements sharing a query reuse cached reports and in-flight
  requests. Offline handling and server-directed rate-limit backoff remain active.
- Vail results are filtered to the exact watched callsign, including portable
  suffixes. Receiver positions use registered HamDB grids and are approximate;
  receivers without a location remain listed. Requests are capped at 500 reports,
  with a warning when more results may be missing.

All four extensions use version **0.3.3**. CWT, MST, and SST behavior is
unchanged; their version bumps are personal packaging changes, exempt from
the temporary CWT upstream synchronization requirement.

Install the `.h2kext` bundle for each extension you use; matching `.sha256`
files accompany each bundle. The RBN network permission changes from
`www.reversebeacon.net` to `vailrerbn.com`. The panel still requires a Ham2K
build with native SVG panel support.

Validation: all **411 tests across 30 files**, lint, strict TypeScript checks,
official builds and packaging, and release checksum validation passed. All
four bundles passed the installed Ham2K Next **26.9.0 build 170** kernel check.
The release review also corrected malformed refresh-test fixtures and added
assertions for successful caching and manual refresh.

Earlier native macOS checks cover the Vail data, settings, and compact layout.
The final manual-refresh button has automated and host-source coverage; the
v0.3.3 archives have not received a fresh native installation/interaction test.
Physical phone and background/screen-lock behavior remain unverified.
