# v0.4.1 — PSK reception and contest-scoped history

Add live PSK Reporter reception maps. Contest history queries can find older
exchanges even after newer contacts in other activities.

## Shared changes

- Updated the Ham2K SDK from 0.5.0 to 0.6.0 and extension tools from 0.3.0 to 0.5.0.
  PSK Reporter requires API 2/build 171 or newer; other extensions retain API 1.
- Updated TypeScript to 7.0.2, LiquidJS to 10.29.0, D3 Geo types to 3.1.1,
  semver types to 7.8.0, and compatible transitive build dependencies.
  Host shared-library compatibility ranges are unchanged.

## n1rwj-cwt

- Request CWT-only QSO history before the host limits results, including both
  exact and portable base calls. Preserve local contest validation for older
  hosts that ignore the filter, plus operator corrections and source precedence.
- Show the total CWT score on the scoring information page.

## n1rwj-mst

- Request MST-only QSO history before the host limits results. Names can be
  recovered from older MST contacts; received serials are never reused.

## n1rwj-rbn

- Reuse a shared reception map and UI with PSK Reporter. Existing
  RBN feed, receiver-directory enrichment, filters, and refresh limits remain.
  Both reception bundles retain the shared map attribution and license notices.
- Explain refresh failures with host error details and separate throttling,
  timeout, HTTP, response, and offline messages. Show attempt, success, and
  retry times, including local cooldowns, with warnings first in Details.

## n1rwj-psk-reporter

- Add live reception maps and lists for **Who hears me** and **Who I hear**, using
  the operation's callsign and reported station grids with the shared RBN map/UI.
- Share one MQTT connection across panels, use narrow callsign subscriptions,
  and bound report storage. Connection status, reconnect backoff, and capacity
  warnings distinguish a live feed from cached reports. No historical backfill
  or background capture is promised; portable-suffix subscriptions are not yet supported.
- Use the published WebSocket SDK and API 2 with permission for
  `mqtt.pskreporter.info`. Requires Ham2K build 171 or newer. The normal package
  replaces the offline preview without changing its extension key.
- Show report-window warnings before explanatory text in Details.

## n1rwj-sst

- Request SST-only QSO history before the host limits results, preserving
  name/location suggestions and portable-call location restrictions.

## Repository notes

- Updated TypeScript in the separate task toolchain and GitHub Actions to
  checkout v7, upload-artifact v7, and mise-action v4.
- Retained Node 24 types for the pinned Node 24 runtime and i18next 23 for
  declared host compatibility. Transitive packages remain within their parents' ranges.
- Mirrored CWT behavior, regression tests, documentation, and required SDK/tools
  updates in the upstream CWT PR checkout. MST/SST and general monorepo tooling
  are exempt from upstream synchronization.
- Host filtering requires a supporting Ham2K build. Older hosts still return
  five unfiltered contacts per call; local validation prevents unrelated suggestions.
- Verified the normal PSK bundle against the published SDK binary bridge and
  official packer; native build-171-or-newer UI/lifecycle testing remains pending.
