# v0.4.0 — RBN spots and contest filters

Find stations in Ham2K's native Spots panel with RBN reports, optional
CWT/MST/SST call-history filtering, and receiver geography controls. My Signal
continues to show who hears your station, independently of Spots preferences.

## n1rwj-cwt

- Makes the cached CWops CWT call-history file available as a reusable filter
  for RBN Spots. Install and enable N1RWJ RBN to receive reports; CWT supplies
  call-history membership without fetching reception reports or sharing exchanges.
- RBN selects CWT by default when available. Choose another filter or **All
  calls** in **Settings → RBN**. A selected missing extension or history file
  yields no spots and an explanation in settings.
- Preserves portable-call matching and rejects ambiguous history matches.
  File membership does not prove current CWT participation; exchange suggestions,
  scoring, and exports are unchanged.

## n1rwj-mst

- Makes the cached ICWC MST call-history file available to N1RWJ RBN. Select
  **MST call-history file** in **Settings → RBN** to narrow native RBN Spots
  without switching the operation's contest.
- Shares callsign membership only, including portable-call matching. Missing
  files produce no matching spots; file membership does not prove current
  participation. Names, per-contact serials, scoring, and exports are unchanged.

## n1rwj-rbn

- Adds **RBN** as a native Spots source for CW, RTTY, FT8, and FT4 across
  160–10 meters, including WARC bands. CW is the default mode.
- Filters spots using cached call-history files supplied by enabled CWT, MST,
  or SST extensions, or allows **All calls**. CWT is the default when available;
  explicit choices persist across restarts and do not follow operation changes.
  A selected missing provider or file yields no spots and an explanation.
- Adds receiver filters for exact skimmer IDs, Maidenhead grid regions,
  continents, and maximum distance in miles from an explicit origin grid.
  All enabled restrictions apply together before reports are deduplicated.
  Refresh **RBN receiver directory** in **Settings → Data Files** after
  upgrading to populate continents in older caches.
- Separates **My Signal — Who hears me** from **Spots — Who I might hear**
  in settings. Spots filters never restrict the My Signal map or reports;
  that panel retains its own operation-specific settings.
- Uses ten-minute Spots snapshots with bounded paging, shared request caching,
  and rate-limit backoff. Failed or offline refreshes retain only unexpired
  reports and reapply current filters. Busy bands may exceed the snapshot limit.
- Receiver locations and distances are estimates. Nearby receiver reports
  do not guarantee that the spotted station is audible at your station.

## n1rwj-sst

- Makes the cached K1USN SST call-history file available to N1RWJ RBN. Select
  **SST call-history file** in **Settings → RBN** to narrow native RBN Spots
  without switching the operation's contest.
- Shares callsign membership only, including portable-call matching. Missing
  files produce no matching spots; file membership does not prove current
  participation. Name/location exchanges, scoring, and exports are unchanged.

## Repository notes

All four extensions and shared workspaces advance together to **0.4.0**.
Install the `.h2kext` bundle for each extension you use; matching `.sha256`
files accompany every bundle. My Signal requires native SVG panel support.

Release tooling now validates one authored notes file and sends each catalog
entry only its own extension section plus any shared changes.

Validation passed: **468 tests across 39 files**, lint, strict TypeScript
checks, four official builds and packages, and release checksum validation.
All four 0.4.0 bundles also passed the installed Ham2K Next **26.9.0 build 170**
JavaScript kernel check; this does not exercise native UI.

CWT behavior and its reusable filter contract are mirrored in
[Ham2K/extensions PR #1](https://github.com/ham2k/extensions/pull/1).
RBN/MST/SST changes, release tooling, and personal versioning/packaging are
exempt from that temporary upstream synchronization requirement.

Earlier native macOS checks on Ham2K Next **26.9.0 build 170** covered live
CW Spots with each contest filter, My Signal rendering, settings persistence,
and receiver geography controls. Live geography-filtered counts were limited
by feed timeouts; deterministic tests cover those combinations. Those checks
used pre-release candidates, not the published 0.4.0 archives. See the
[verification record](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/v0.4.0/docs/VERIFICATION.md).
