# v0.5.0 — Temporary CQ WW RTTY preview

Adds a temporary CQ WW extension whose RTTY improvements are intended for
the official Ham2K CQ WW extension in
[Ham2K/extensions PR #2](https://github.com/ham2k/extensions/pull/2). Also includes the CWT/MST/SST history fix prepared for v0.4.3, preserving
current-operation exchanges when scoring resumes from a named checkpoint.

## n1rwj-cqww

New temporary preview of the official CQ WW extension with RTTY exchange
entry, 1/2/3-point scoring, per-band zone/country/W-VE multipliers, duplicate
warnings, and ADIF/Cabrillo exports. Handles Canadian contest call areas,
RTTY sideband names, and operator corrections and clearing. Supports
single-operator and checklog entries; radio/modem operation remains external.

Disable official CQ WW before enabling this preview. Saved `cqww` activities
and exchanges remain compatible with the planned official update.
Track [Ham2K/extensions PR #2](https://github.com/ham2k/extensions/pull/2).
Once an official CQ WW release includes that PR, remove this temporary
extension and enable the updated official CQ WW extension. A merged PR alone
does not mean the changes are available in the installed official version.
See the
[operator and migration guide](https://github.com/rwjblue/ham2k-n1rwj-extensions/blob/main/extensions/contests/n1rwj-cqww/README.md).

## n1rwj-cwt

Preserve exchanges from earlier contacts in the current operation when
scoring resumes after an appended contact. Concurrent lookups share one
membership reload, so downloaded history cannot override those exchanges.
This fix is also maintained in
[Ham2K/extensions PR #1](https://github.com/ham2k/extensions/pull/1).

## n1rwj-mst

Preserve current-operation history after scoring resumes from a named
checkpoint. The shared history adapter reloads membership once; received
serial numbers remain per contact and are never history suggestions.

## n1rwj-psk-reporter

No extension-specific changes for N1RWJ PSK Reporter.

## n1rwj-rbn

No extension-specific changes for N1RWJ RBN.

## n1rwj-sst

Preserve current-operation exchange history when scoring resumes from a named
checkpoint, sharing one membership reload across concurrent lookups.

## Repository notes

All workspaces advance to the synchronized 0.5.0 version. Root dependencies
are unchanged. The CQ WW source retains Sebastian Delmont's MIT license and
is synchronized with the separate upstream CQ WW contribution. The CQ WW addition does not
modify CWT behavior or belong on the CWT PR branch. The separately developed
checkpoint history fix already on main is included in this release; v0.4.3
was prepared but not published. The installed-kernel verifier now supplies the performance clock and awaits
asynchronous activation required by Ham2K build 174. Native UI and on-air
verification remain separate from automated source, bundle, and kernel checks.
